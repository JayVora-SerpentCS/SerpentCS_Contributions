Project - Status by Recent Activities

This module helps the project management team to know the idle projects by the last updated date on the project and recent updated date for the Project communication.

Highlighted Features

Idle Project Tracking

Identify projects that have not been updated recently.

Automatic Date & Time Updates

Key fields such as Last Update On and Recent Log Date are automatically updated based on task creation or activity, ensuring accurate tracking without manual effort.

Time-Saving

Helps project managers take quick decisions by showing clear project activity status.

Communication Updates

View the most recent updates and discussions on projects.

  • Features
  • Screenshots

Flexible Task Stages

Users can create custom task stages and manually move tasks between stages to reflect real-time progress.

Project Creation & Management

Users can create new projects with specific names and configurations. Upon creation, the system automatically records the project’s creation date and time in the Last Update On field.

Automatic Recent Date Logging

When a task is created or updated, the Recent Date field is automatically populated with the current date and time, ensuring accurate activity logs.

Project-Level Updates from Tasks

Any task-related activity automatically updates project-level fields like Last Update On and Recent Log Date in the Project Kanban view.
